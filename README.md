# 🐟 摸魚水族館 (Idle Fish Tank) - Chrome 擴充套件 & GitHub Pages 雲端網頁版

專為上班族、學生打造的放置型療癒養魚遊戲！隨時點開瀏覽器右上角或網頁版，看著小魚悠游擺尾、投餵飼料、離線自動累積金幣、打造專屬水族箱，支援 **Google 一鍵登入與 Firebase 雲端存檔跨裝置同步**！

---

## ☁️ 雲端同步與存檔備份功能

* **Google 一鍵登入**：點擊水族箱右上角「👤 登入」，登入 Google 帳號即可綁定進度。
* **智慧雲端同步**：自動比對雲端與本地存檔時間戳，切換裝置自動下載最新魚缸，遊玩時自動非同步備份至 Firebase Firestore。
* **本機 JSON 備份/還原**：一鍵將存檔匯出為 `.json` 檔案下載至電腦，亦可隨時匯入備份檔還原魚缸！
* **離線與訪客保護**：未登入時以訪客模式儲存於本機，離線遊玩不卡頓。

## 🌐 GitHub Pages 部署步驟

本專案已產出標準響應式 `index.html`，可直接託管於 GitHub Pages：

1. **推送至 GitHub 倉庫**：
   ```bash
   git add .
   git commit -m "feat: Firebase 雲端存檔與 GitHub Pages 支援"
   git remote add origin https://github.com/<你的使用者名稱>/<你的倉庫名稱>.git
   git branch -M main
   git push -u origin main
   ```
2. **開啟 GitHub Pages**：
   * 前往 GitHub 倉庫頁面 -> 點擊 **Settings** -> 左側選單選擇 **Pages**。
   * 在 **Build and deployment** 下方的 **Source** 選擇 `Deploy from a branch`。
   * **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
   * 約 1~2 分鐘後，即可透過 `https://<你的使用者名稱>.github.io/<你的倉庫名稱>/` 在任何電腦或手機瀏覽器暢玩水族館！
3. **設定 Firebase Authorized Domains (授權網域)**：
   * 前往 [Firebase Console](https://console.firebase.google.com/) -> 進入專案 `idle-fish-tank`。
   * 點選 **Authentication** -> **Settings (設定)** -> **Authorized domains (已授權網域)**。
   * 點擊 **新增網域**，輸入你的 GitHub Pages 網域（例如：`<你的使用者名稱>.github.io`），即可啟用該網頁的 Google 登入功能！

## 🚀 如何在 Chrome 安裝擴充套件

只需 3 步驟即可載入：

1. 打開 Google Chrome 瀏覽器，在網址列輸入並前往：
   ```
   chrome://extensions/
   ```
2. 開啟右上角的 **「開發人員模式」 (Developer mode)** 開關。
3. 點擊左上角的 **「載入未封裝項目」 (Load unpacked)** 按鈕，並選取本專案資料夾：
   ```
   C:\Users\john.hu\.gemini\antigravity\scratch\chrome-fish-tank-game
   ```
4. 安裝完成！點擊 Chrome 右上角拼圖圖示（擴充功能選單），將 **「摸魚水族館」** 固定（Pin）到工具列上，隨時點開摸魚！

> 💡 **免安裝直接預覽測試**：你也可以直接用 Chrome 雙擊打開 `popup.html` 立即在瀏覽器中全螢幕試玩！

## 🌊 超活躍小魚游動系統

* **擬真擺尾衝刺與滑行 (Burst-and-Coast)**：小魚不再是呆板勻速移動，而是像真魚一樣尾巴快速一擺衝刺，再順著水流流暢滑行。
* **S 型波浪弧線巡游 (Sinusoidal Motion)**：游動方向呈現自然平滑的曲線弧度，不再是機械式直線折線。
* **多維度深度探索**：小魚會主動向下俯衝探索底砂與水草，或游上水面換氣吐出微型氣泡 🫧。
* **滑鼠游標感知互動**：滑鼠在魚缸上移動時，周遭小魚會好奇探頭靠攏或靈活閃避嬉戲！

## 🎨 如何使用網路上的魚圖檔？

支援**兩種非常簡單的方式**：

### 方法一：直接在遊戲內貼上「圖片網址 (URL)」或上傳（推薦！免動程式碼）
1. 點擊水族箱下方的 **「🎨 自訂魚」** 按鈕。
2. 預設即為 **「🌐 貼上圖片網址」** 模式：
   * 在輸入框貼上任何公開的圖片網址（例如 `https://example.com/cute_fish.png`）。
   * 系統會**自動即時驗證並顯示預覽**！
   * 甚至提供了 **「🐡 刺河豚」、「🦈 呆萌小鯊」、「🦑 螢光烏賊」** 的快速測試按鈕，點一下就能直接體驗！
3. 也可切換到 **「📁 本機檔案上傳」** 從電腦選取透明去背圖（PNG、GIF、WebP）。
4. 輸入小魚名字，點擊「放流進水族箱」，專屬小魚就會立即游進魚缸！程式會自動處理轉向翻轉與水流擺動動畫。

### 方法二：放入擴充功能資料夾
1. 將你抓取的圖片放入 `assets/` 資料夾（例如 `assets/my_fish.png`）。
2. 在 `js/fish.js` 的 `FISH_SPECIES` 中隨時將圖片路徑指過去即可！
